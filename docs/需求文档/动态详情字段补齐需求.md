# C-53 动态详情字段补齐需求文档

> 版本：1.0｜日期：2026-10-26｜状态：实施前设计，尚未实现
> 面向：产品、前后端研发、测试。配套：[开发文档](../开发文档/动态详情字段补齐开发.md)。

## 1. 背景与现状纠偏

动态发布、详情、信息流和互动模块已经有后端实现，不能将此项理解为重做发布模块。

当前 `PostResponse` 有正文、摘要、媒体、时间、状态、版本和真实互动字段；前端 `normalizePost` 还读取 `title/note/comments/displayTime`。但“读取了字段”不等于“字段必须新增到数据库”：

- `title/note` 不在当前发布表单和请求中。
- 详情 `App.vue.openPost` 已并行调用动态详情与评论接口，然后合并评论；不需要重复内嵌整份评论。
- `displayTime` 是随时间变化的展示文案，应优先由前端根据 UTC 时间生成。

本次采用最小兼容方案：冻结基础字段契约、修复空占位和时间展示、独立处理评论加载；不擅自新增标题/备注创作能力。若未来需要用户编辑标题与备注，应另行评审字段、长度、编辑和迁移规则。

## 2. 目标与范围

- 动态列表、详情、收藏使用相同基础视图，已实现的互动数不再被描述为固定占位。
- 没有标题或备注时，不显示空标题区域和空“创作进展”卡片。
- 评论失败不能导致已成功的动态详情不可用，不能把“加载失败”显示为“暂无评论”。
- 草稿和定时仅作者可读，删除或无权限内容不在页面残留。
- 本期不新增帖子字段存储、不增加评论层级、不做编辑器和发布状态机重构。

## 3. 字段契约

| 字段 | 本期规则 |
|---|---|
| id/author/topic | 沿用后端；草稿 topic 可空，前端不展示空话题胶囊 |
| content | 正文纯文本字符串；空行分段，禁止当 HTML 渲染 |
| summary | 后端生成的列表摘要；不是用户编辑标题 |
| mediaType/media | 沿用当前 DTO，媒体排序由 sortOrder 明确 |
| status/version/ownedByMe | 沿用；权限以服务端判断为准 |
| scheduledAt/publishedAt/editedAt/createdAt | UTC 时间，按状态选择展示 |
| likeCount/likedByMe/bookmarkedByMe/commentCount | 后端真实数据；commentCount 包含回复，不由已加载数组长度替代 |
| title/note | 本期不是必需服务端字段；兼容已有数据但为空时隐藏组件 |
| comments | 评论由 D5 返回并合并到前端本地状态；不要求基础 PostResponse 返回 |
| displayTime | 前端生成相对时间，服务端无需返回动态中文字符串 |

媒体响应本身可含 `sizeBytes`，前端预览当前不使用不代表后端不能返回。所有 ID 按字符串处理。

## 4. 用户流程和页面状态

1. 点击列表动态打开详情，清除上一条动态的回复输入和评论状态。
2. 独立加载详情与首屏评论；详情成功即展示正文、媒体和互动。
3. 评论成功展示前两级，维护 `nextCursor`；未加载完明确显示“加载更多”，回复截断显示提示。
4. 评论失败显示可重试状态，不影响已加载的正文；详情 404 时关闭或替换旧内容，不展示上一条帖子。
5. 发表或回复成功后增加当前动态 commentCount，并以返回 ID 去重；随后刷新时用服务端计数覆盖。
6. 用户快速切换两条动态时，旧请求结果不能覆盖当前动态；草稿详情不自动请求只支持已发布动态的评论接口。

## 5. 展示规则

- 已发布内容优先展示 publishedAt，未发布内容展示 createdAt；editedAt 以独立“已编辑”提示展示，不替代发布时间。
- 相对时间采用用户本地时区：一分钟内“刚刚”、小时/天范围相对展示，较旧内容展示本地日期；完整时间可作为 title/无障碍文本。未来定时时间显示“计划发布”，不得显示负数分钟前。
- 空 title 不制造虚假标题；正文必须保留可访问的文章结构，可用隐藏的“动态详情”标识。
- 空 note 隐藏“创作进展”；已有非空兼容值仍可展示。
- 默认空评论数组是页面初始化状态，不代表接口加载完成。

## 6. 接口范围与异常

复用 C2 `GET /posts/{id}`、D5 `GET /posts/{id}/comments?limit=20&cursor=...`，以及现有列表和互动接口。评论加载更多只使用 D5；不新增重复评论接口。

- 404 POST_NOT_FOUND：动态不可见，清除对应详情状态。
- 401：需要重新登录的私有动态不保留敏感内容。
- 评论网络/服务错误：显示局部重试，保留已加载评论。
- 非法时间：显示“时间未知”，不得渲染 Invalid Date。

## 7. 验收标准

- [ ] 不带 title/note/comments/displayTime 的当前后端响应能完整展示动态，无空占位卡片。
- [ ] 列表、详情、收藏的真实互动数与按钮状态一致；游客状态为 false。
- [ ] 详情成功、评论失败时正文仍可读且评论有重试入口；详情失败不残留旧详情。
- [ ] 评论游标续页 ID 去重，计数不会被首屏 20 条覆盖；repliesTruncated 有明确提示。
- [ ] 纯文本包含 HTML 标签时只显示文本，不执行脚本；emoji 和多段正文不破坏展示。
- [ ] UTC 时间正确转换，本地跨天、未来定时、已编辑、无效时间均正确。
- [ ] 草稿/定时只有作者可见；草稿详情不因评论不可用而整体报错。
- [ ] 快速切换动态、重复点击、迟到请求不会覆盖当前内容。

## 8. 交付边界

主要为前端契约与展示补齐、必要的后端契约测试及接口文档澄清，不默认增加数据库列。本需求替代接口清单中“缺字段一律后端补齐”的推断；后续同步清单时需说明 comments/displayTime 属于组合和派生数据。
